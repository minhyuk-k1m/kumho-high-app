# 🏫 금호고 스쿨메이트 (Kumho SchoolMate)

> **광주 금호고등학교(Kumho High School) 재학생을 위한 실시간 스마트 학생 포털 웹 애플리케이션**

금호고등학교 재학생들이 매일 궁금해하는 **오늘의 급식(중식 및 석식)**, **학사일정 및 시험 D-Day**, **학급별 실시간 시간표**, **리로스쿨(RiRoSchool) 및 학교 공식 서비스 바로가기**를 모바일 최적화 UI로 빠르고 깔끔하게 제공합니다.

---

## 🌟 주요 특징 및 기능

### 1. 🍱 오늘의 급식 (중식 & 석식 완벽 지원)
- **점심(중식)과 저녁(석식 - 야간자율학습 및 기숙사생)** 분리 표시
- 메뉴별 칼로리(Kcal) 및 탄수화물, 단백질, 지방 등 상세 영양 성분 제공
- **내 알레르기 설정 & 스마트 경고**: 난류, 우유, 밀, 땅콩, 돼지고기 등 19종 알레르기 식품 중 본인에게 해당하는 식품을 설정해두면 해당 메뉴에 시각적 하이라이트와 경고 배지 자동 부착
- 날짜 탐색: 어제, 오늘, 내일 및 달력 선택을 통해 다른 날짜의 식단도 자유롭게 조회

### 2. 📅 학사일정 및 주요 시험 D-Day
- 이번 달 및 원하는 월의 학사일정 전체 목록 확인
- **학년별 필터링**: 전체, 1학년, 2학년, 3학년 대상 행사만 골라보기
- **시험 D-Day 카운트다운**: 1·2차 정기시험(중간/기말고사), 모의평가, 전국연합학력평가, 수능, 방학 등 주요 일정 D-Day 자동 계산 및 상단 배너 노출

### 3. ⏰ 우리반 실시간 시간표
- **1~3학년 1~10반** 실시간 나이스(NEIS) 시간표 연동
- 교시별(1~7교시) 과목명과 금호고 공식 일과시간표(08:40 ~ 16:20) 매핑
- **"내 반으로 저장"**: 본인의 학년과 반을 브라우저에 저장하여 다음 접속 시 자동으로 본인 반 시간표 로드

### 4. 🔗 재학생 필수 포털 허브
- **금호고 리로스쿨** (`https://kumho.riroschool.kr/`) 원터치 바로가기
- **금호고 공식 홈페이지** (`https://kumho.jge.hs.kr/`)
- **독서로 금호고 도서검색** (도서 대출 현황 조회)
- **학교알리미** 및 교무실(`062-608-1000`), 행정실(`062-608-1004`) 바로 전화걸기

### 5. 🎨 모바일 퍼스트 디자인 & UX
- 금호고등학교의 교색(네이비 블루 & 골드)을 현대적으로 재해석한 깔끔한 카드 디자인
- 시스템 설정 연동 및 수동 스위치가 포함된 **다크 모드(Dark Mode)**
- 반응형 웹으로 PC 모니터는 물론 스마트폰, 태블릿, PWA 홈 화면 추가 지원

## 🛠 기술 스택 및 데이터 소스

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript (ES6+), Lucide Icons
- **Data Source**: 교육부 **나이스(NEIS) 교육정보개방포털 공식 Open API**
  - 관할 교육청: `F10` (광주광역시교육청)
  - 학교 표준 코드: `7140341` (금호고등학교)
  - 급식식단정보 (`mealServiceDietInfo`)
  - 학사일정 (`SchoolSchedule`)
  - 고등학교시간표 (`hisTimetable`)
- **인프라/빌드**: 별도의 npm 빌드나 무거운 서버 없이 **브라우저 단독 실행(Serverless/Static)** 가능

## 🚀 실행 방법

### 방법 1. 간편 실행 (가장 추천)
- 폴더 내의 **`start.bat`** 파일을 더블클릭하거나,
- **`index.html`** 파일을 크롬, 엣지, 사파리 등 웹 브라우저로 바로 엽니다.

### 방법 2. 로컬 웹 서버 실행 (PowerShell)
PowerShell 콘솔에서 아래 스크립트를 실행하면 내장 로컬 HTTP 서버가 실행되며 브라우저가 자동 실행됩니다:
```powershell
powershell -ExecutionPolicy Bypass -File .\start_server.ps1
```
- 브라우저 접속 주소: `http://localhost:8080/`

## 🌐 무료 웹 배포 방법 (학생들과 공유할 때)

이 프로젝트는 순수 정적 웹 앱으로 구성되어 있어 누구나 무료로 1분 만에 웹에 배포할 수 있습니다:

1. **GitHub Pages**:
   - GitHub 저장소 생성 후 본 파일들을 업로드 (`git push`)
   - Repository `Settings` -> `Pages` -> Source를 `main` 브랜치로 설정하면 `https://[아이디].github.io/[저장소명]` 주소로 전교생이 즉시 사용 가능합니다.
2. **Vercel / Netlify / Cloudflare Pages**:
   - 해당 폴더를 드래그 앤 드롭하기만 하면 30초 만에 전세계 어디서나 접속 가능한 HTTPS 주소가 발급됩니다.
